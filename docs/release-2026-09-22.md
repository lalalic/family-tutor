## Final signed-in browser acceptance

These steps require the customer's signed-in Chrome/ChatGPT account and are intentionally not bypassed by automation.

1. Download the public Family Tutor extension ZIP and unzip it.
2. In Chrome's extensions page, enable Developer mode and **Load unpacked** using the unzipped 2.6.5 folder. If Family Tutor is already installed unpacked, reload/replace it with 2.6.5.
3. Open the Family Tutor extension and confirm it shows **Connected** and the expected learners. Relink a learner only if the popup shows that learner as unlinked.
4. In ChatGPT, reconnect/reinstall the Family Tutor MCP connector so ChatGPT reloads the current tool schema. If the install UI requests an auth token, choose **Connect ChatGPT** in the extension and paste the copied dedicated token. Do not paste the extension session/refresh token.
5. Send one child message from Discord and confirm its reply returns to that child channel.
6. From the parent channel, send a reminder targeting the child. Acceptance requires both: the reminder is delivered to the child through the opaque `channelId` target and the parent receives confirmation through the inbound correlation.
7. Trigger/request a fresh tutor thread once more and confirm the next child message receives a reply; this is the signed-in smoke check for rollover after connector refresh.

## Recovery

If the extension loses its hosted session, use **Reconnect**. If learner bindings are missing, open each learner's ChatGPT Project/thread and use **Link**. If a parent reminder confirms to the parent but does not reach the child, reconnect the ChatGPT connector first; this indicates ChatGPT is still using an older cached MCP tool schema.

If setup is interrupted before the extension is installed, reopen the setup claim page within 30 minutes. It provides the current extension download and resumes automatic claim redemption after the extension is loaded.
