Setup Help

Follow these steps once. Family Tutor can try to automate the safe parts, but ChatGPT may still require you to confirm Developer Mode, app creation, or authorization.

Optional: try auto setup

Family Tutor will try to create/link kid projects, prepare the ChatGPT auth token, and open the ChatGPT setup screen. If ChatGPT requires a confirmation, finish that step manually and continue below.

1

Turn on ChatGPT Developer Mode

Open ChatGPT settings, go to Apps / advanced settings, and enable Developer Mode.

2

Add Family Tutor to ChatGPT

Create a ChatGPT app / MCP connection using:

https://family-tutor.qili2.com/mcp

3

Create one ChatGPT Project for each kid

Use the kid's name as the Project name. Family Tutor can try this automatically; if ChatGPT's UI asks for confirmation, complete it there.

    4

    Check that everything is connected

    Every kid should show as linked and Family Tutor should show Connected.

    5

    Send a test message

    Send a short message in one kid's Discord channel. A correct setup replies in that same channel. You can then test a parent reminder separately.
